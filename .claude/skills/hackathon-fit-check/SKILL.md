# Hackathon fit check — a real decision, not a reflex yes

## The five questions, in order

1. **Is what you'd show genuinely new, or existing work?** Check the
   actual merge/commit date of whatever you'd submit against the
   program's actual window (registration open → submission deadline).
   If it predates the window, it's existing work — that's not
   automatically disqualifying, but it changes questions 2-3.

2. **If it's existing work, does the judge/sponsor already know its real
   age?** If the same person who'd judge your submission personally
   reviewed/merged/saw that work before the program started, presenting
   it as built-for-this-program is a real trust risk with that specific
   person — not an abstract ethics question. Check who's actually
   judging before answering this.

3. **What's the real relationship value vs. the prize-pool odds?** A
   sponsor-run bounty where the sponsor picks winners directly is a
   fundamentally different bet than an independent judge splitting a
   pool among dozens of entrants. Weigh an existing real relationship
   (a partner who already works with you, controls their own bounty)
   much higher than anonymous odds against a large field.

4. **Verify the actual timeline, live — never assume from a cached
   description.** Registration deadline, submission deadline, and
   whether they're the same date (some programs collapse both into one
   cutoff, leaving zero build time after registering). Check the live
   countdown/page, not a remembered date.

5. **Does the program's actual thesis match what you'd build, or would
   you be stretching a fit?** If the flagship challenge is a specific
   feature unrelated to your product, don't force a submission into it
   just to participate — check whether a secondary "any app" track
   exists that's a real fit instead.

## Decision output

State plainly: participate / don't participate / ask the sponsor
directly before deciding — with the specific question (1)-(5) that
drove the answer named explicitly, not a vague "seems risky." If the
honest answer depends on something only the sponsor can confirm (does
pre-built work count, is there a specific track that fits), draft that
question rather than guessing either way.
